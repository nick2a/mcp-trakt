Trakt uses OAuth 2.0. The `npm run setup` script handles the full Authorization
Code + PKCE flow — no client secret, and you never manage tokens manually.

## ⚙️ How it works

1. Set your app's redirect URI to exactly `http://localhost:8080/callback` at
   [trakt.tv/oauth/applications](https://trakt.tv/oauth/applications)
2. Run `npm run setup` and enter your **Client ID**
3. Approve access in the browser window that opens; setup receives Trakt's
   redirect on `localhost:8080`
4. Tokens are saved to the macOS Keychain (never printed) — the server reads
   them automatically on every start

To refresh an expired token, just run `npm run setup` again.

## 🧪 Test your credentials

```bash
curl -s https://api.trakt.tv/users/me \
  -H "trakt-api-version: 2" \
  -H "trakt-api-key: YOUR_CLIENT_ID" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" | jq .username
```

## 🛡️ Security best practices

- Credentials are stored in the macOS Keychain — never in plain files or config
- Rotate your access token if it is accidentally exposed — run `npm run setup`
  again
- Trakt access tokens expire after 90 days — re-run `npm run setup` to refresh
- Treat your access token like a password: full account access with
  history/checkin write rights
